## 📝 About The Project

This is a responsive website based on the popular TV series Rick and Morty. Using modern web technologies, it provides an engaging and user-friendly experience for fans of the series.

## ✨ Features

- 📱 Fully responsive design
- 🎨 Engaging and user-friendly interface
- 🌈 Visual theme inspired by the series
- ⚡️ Fast and optimized performance

## 🛠️ Built With

- React.js
- Tailwind CSS
- Rick and Morty API

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/[your-username]/Rick-and-Morty---Responsive.git
```

2. Navigate to the project directory:

```bash
cd Rick-and-Morty---Responsive
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```

5. Open your browser and navigate to `http://localhost:3000` (or the port shown in your terminal).
